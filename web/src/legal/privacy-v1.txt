数据与隐私（v1 · 2026-10-30）

这页说清楚三件事：面板在本机存了什么、往外面发了什么、你想删的时候删什么。
它不是协议，没有法律效力；有法律效力的是《使用条款》v3 与 Mojang EULA。

一、存在本机的东西

账号：用户名，以及加盐的 PBKDF2 口令哈希（默认 21 万次迭代）。不存明文。
开发者密码：同上，也只有哈希。
会话：登录后生成的随机令牌，只放在内存里；面板重启就全部失效。
实例：每个实例的配置、它自己的 HOME 目录、安装的版本与插件。
凭据：你给实例填的 API Key 等，落在该实例目录里。面板不额外加密，靠文件权限。
审计：登录、提权、启停、开关功能等动作，记时间、账号、来源 IP、User-Agent。
MC 同意记录：条款版本、文本哈希、EULA 哈希与拉取时间、同意时间、账号、来源 IP、
确认方式、客户端 UA、构建号。

二、不会发出去的东西

没有遥测、没有使用统计、没有崩溃上报。作者这边收不到任何数据——
这个面板没有「关闭数据上报」的开关，因为它本来就不上报。

三、会主动访问的外部服务（对方能看到你服务器的 IP）

npm 镜像或你配置的下载源：安装/更新 dsh、品牌工具、插件。
Mojang：Minecraft 版本清单、服务端 jar 与 EULA 正文。
models.dev：模型与供应商目录（填 API Key 时的下拉）。
GitHub Releases：部分品牌组件的发行包。
这些请求只用于下载与查询，不带你的账号、实例内容或审计记录。

四、存在哪、留多久

全部在数据目录下（默认 /data；MC 可以用 mc.dataDir 指到别处）。
审计日志与同意记录目前不会自动清理：条款 5.3 写的保留期是目标，不是当前行为。
删多少、留多久，由你决定。

五、你能删什么、怎么带走

删实例：面板会先备份再删目录。
删审计与日志：直接删文件。
完全清除：停面板，删数据目录；容器部署就删卷。
导出：库里都是 JSON 与纯文本，直接拷走即可。

六、面向他人开放时

玩家用户名、UUID、IP 属于个人信息，你（运营者）是处理者，
需要自己完成告知、取得同意、未成年人保护与防沉迷等义务。

七、联系

问题与删除请求走仓库 Issues。
