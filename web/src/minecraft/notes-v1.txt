开 Minecraft 服务器之前，花两分钟读完这页

这不是协议，没有法律效力。有法律效力的是 Mojang EULA 和《使用条款》v3。
这页只讲一件事：你点下的每个按钮，机器上实际会发生什么。

──────────────────────────────
这个功能是什么

面板帮你下载一个原版服务端，启动它、停止它、备份它的存档，并记下你做过什么。
就这些。它不把服开到公网，不管插件模组，也管不了熊孩子和外挂。

──────────────────────────────
开服前，检查四样东西

端口。
服务端监听所有网卡。用 Docker 部署时默认只发布了面板端口，这时谁也连不进来——包括你自己和朋友。要让人玩，得自己把游戏端口映射出去（比如 25565:25565）。
注意：改映射要重启容器，重启会把正在跑的服停掉，而且不会自动拉回来。

正版验证和白名单。
online-mode=true 别关。关了之后任何人能冒用任何名字进来，包括你的。white-list 建议开，开了记得先加自己。

内存。
2 GB 起步，新版本建议 4 GB 以上。别超过机器内存的一半——服务端和面板吃同一个机器的资源，给多了两边一起卡。

权限（最重要的一条）。
服务端和面板跑在同一个系统用户下。服被漏洞打穿，约等于面板被打穿：存档、会话、凭据，同一个用户全都读得到。面板不是沙箱。要真隔离，用独立用户或独立容器跑。

──────────────────────────────
开服之后，机器上多了什么

一个 java 进程（-Xmx2048M -jar server.jar nogui）、一对端口（游戏端口 + 默认关闭的 RCON），和一个实例目录：

  <数据根>/minecraft/instances/<实例ID>/
  ├── world/              存档，最值钱的东西
  ├── logs/latest.log     出事先看它
  ├── server.properties   面板管的配置，含 RCON 密码
  └── backups/            备份 zip

同一个版本的 server.jar 全实例共用一份，下载时校验过 SHA-1。

──────────────────────────────
五件最容易搞砸的事

1. 关网页 ≠ 关服。浏览器关了服还在跑。要停，在面板里点「停止」。
2. 别杀进程。强杀会撕存档。「停止」会等它打完 "All chunks are saved" 才退出。
3. 版本只能升，不能降。存档被新版本打开过就回不去旧版本了。而且切换版本不会自动备份（只有删实例、恢复备份会）——想降级，先手动备份。
4. 游戏端口和 RCON 端口是一对。改就一起改。
5. 别在服运行时重启容器或断电。服跟着进程一起死，不会自动拉起，没存完的部分直接丢。

──────────────────────────────
崩溃了会怎样

它不会自己重启。进程意外退出，实例标记为「失败」，留下退出码和错误信息，然后停在那等你。
这是故意的：自动重启会让一个坏掉的服反复撕存档。先看 logs/latest.log 最后几十行，确认是不是内存给少了，再决定要不要重新启动。

──────────────────────────────
关于自动化和 AI agent

面板上每个按钮背后都是一个 HTTP 接口。也就是说：curl、脚本、AI agent 能做的事和你手动点一模一样——只要有你的登录态（加上开发者密码）。审计日志里它和你记在同一个账号名下，只能靠 IP 和浏览器指纹分辨。

所以：面板密码就是最高权限。别给自动化长期凭据，用完就吊销。条款 3.5 写明了「你通过 API 或 AI agent 发起的操作视同你本人操作」——出了事，是你的操作。

──────────────────────────────
出事了，按这个顺序来

先停服，等它存完。不 kill 进程，不在没备份时删东西。

存档坏了：别覆盖。去 backups/ 找最近一份能开的。

怀疑被入侵：停服 → 撤掉端口映射 → 改面板密码和开发者密码 → 翻 audit-*.jsonl 和 latest.log → 再决定怎么办。

面板不对劲：当「面板失守」处理，不是「游戏服失守」——它们同一个用户，见上面「权限」那条。

──────────────────────────────
三句条款里不会直说的真话

1. 备份不是保险。备份和世界在同一块盘上，盘挂了一起挂，而且备份不会自动清理、越攒越多（面板目前也没有磁盘余量检查）。重要的存档，自己往别的机器拷一份。
2. 条款里的 1000 元上限，赔的是数据恢复的服务费，不是存档本身的价值。存档值多少钱，条款明确不管。
3. 「停止功能」后的一小时锁定挡不住人。重启面板就没了。它是防止手滑的摩擦，不是安全边界。

──────────────────────────────
面板替你做和不替你做的

替你做：校验下载文件、分配端口、优雅停服、删实例前强制备份、留审计、拒绝太旧的 Java。
不替你做：沙箱隔离、防火墙、异地备份、服务端更新、插件安全性，以及实名、防沉迷、个人信息、税务这些合规的事。
