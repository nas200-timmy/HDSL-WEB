# 种子地图

> 给一个版本和一个种子，出一张图，用来在开世界之前判断"这个世界值不值得开"。

## 是什么

种子地图是面板里的一个独立页面（不依附任何一台服务器实例）：选版本、填种子，
几秒到几分钟后得到一张俯视图，标出群系、结构、史莱姆区块，可以缩放、拖动、
选点读坐标。

它的价值在"开荒前"：看一眼出生点附近是海洋还是森林，最近的村庄有多远，
值不值得换一个种子。

## 能做什么

- **群系地图**：陆地、海洋、河流、沙漠、雪原、恶地……按群系上色；
- **结构落点**：村庄、神殿、要塞、矿井、沉船、海底废墟、远古城市等；
- **史莱姆区块**：按种子公式直接算，不需要生成；
- **坐标读数**：鼠标指到哪，状态栏显示世界坐标与群系；
- **测距**：在地图上点几个点，读出距离；
- **历史**：最近 30 次结果落盘保存，重启不丢，按种子分组折叠；可删单条、整个种子组或清空。

## 两种引擎

同一个种子，两种算法，界面上可以切换：

| 引擎 | 怎么算 | 速度 | 精度 |
|---|---|---|---|
| **Java 内核** | 直接计算气候参数与结构落点，不生成世界 | 秒级，可铺到 16384×16384 格 | 近似（见下） |
| **服务端** | 真起一个一次性服务端生成区块，读它写出的群系 | 分钟级 | 与游戏一致 |

**怎么选**：想看大范围、看大概，用 Java；想按坐标找具体群系，用服务端。

服务端模式用完即删临时世界，不影响任何正在运行的服务器。

## 支持的版本

**1.12.2 到最新正式版**。1.12.2 是兼容下限，更早的版本不做。

| 版本 | 族 |
|---|---|
| 1.21.x | 现代（multi-noise） |
| 1.20.x / 1.18.x | 现代（同一套气候系统，参数不同） |
| 1.16.x | 旧层栈，三维群系 |
| 1.14.x | 旧层栈，二维群系 |
| 1.12.2 | 旧层栈（下限） |

版本没下载过时，第一次预览会现场下载官方服务端并校验哈希，之后一直缓存。

## 精度

**Java 内核与游戏的真实差异**（固定种子、真服务端逐格对比）：

| 版本 | 吻合率 | 主要差异 |
|---|---|---|
| 1.12.2 | 77.8% | 丘陵变体 |
| 1.14.4 | 75.0% | 丘陵变体 |
| 1.16.5 | 78.0% | **全部**是 `forest → wooded_hills` |
| 1.21.4 | 69.6% | 地表位置返回洞穴群系 |

差异集中在"丘陵变体"上：游戏说森林，内核有约两成情况说森林丘陵。这对"看个
大概"几乎无影响，对"按坐标找具体群系"有影响。

完整的方法、数字与解释见 [seedmap-deviations.md](seedmap-deviations.md)。

**内核与 cubiomes 的 C 版逐格一致**（18432 个采样点，0 差异），所以这些差异
来自上游实现与游戏之间，不是移植错误。

## 为什么 Java 模式快

服务端模式在**生成世界**：每个区块 15 毫秒到 0.9 秒，1024×1024 格就要一分半
到跑不完。

Java 内核只算气候参数，不生成方块、不点灯、不刷实体。同样一块区域，
服务端要二十分钟，内核是一到两秒。

## 内核是独立的

算法部分（`minecraft/seedmap/core`）**零依赖**：只用 JDK 标准库，不 import
面板的任何类，可以脱离面板单独编译运行。面板侧只有一个适配层，负责渲染图片、
写缓存、拼 JSON。

这样做的原因很实际：这份代码是移植来的，将来可能被单独拿走使用，或者换一个
前端复用。所以它不能长在面板的生命周期上。

## 怎么用

1. MC 列表 → 工具栏「种子预览」，或直接访问 `/mc/preview`；
2. 选版本、填种子（数字或文本）、选方案与范围；
3. 生成后：滚轮/双指缩放，拖动平移，单击选点，双击复位；
4. 左下角显示坐标与群系，右下角是比例尺与图例。

侧边可以开关网格、史莱姆区块、结构图层，结构可以按类型过滤。

## 验证

三层差分验证，任何一层不过，该版本不默认启用新内核：

| 层 | 对照 | 现状 |
|---|---|---|
| L1 | 与 cubiomes 的 C 版逐点比对 | **18432 点，0 差异** |
| L2 | 与游戏自带的群系源比对 | 未建（用它裁决上游与游戏的分歧） |
| L3 | 与真服务端生成的区块比对 | 已跑，结果见精度一节 |

## 已知限制

- **丘陵偏差**：旧版约两成情况下把母群系报成丘陵变体；
- **新版洞穴采样**：1.18+ 的地表采样点偏低，可能返回洞穴群系；
- **服务端模式慢**：范围越大越慢，2048×2048 以上建议用 Java 模式；
- **Java 模式没有地形起伏**：只有群系色块，没有高度明暗与地表材质。

## 代码在哪

| 位置 | 内容 |
|---|---|
| `minecraft/seedmap/core` | 内核：噪声、层栈、气候参数、结构定位（零依赖） |
| `minecraft/seedmap/adapter` | 适配：把内核结果渲染成图片与元数据 |
| `minecraft/preview` | 服务端模式：起服、读区块、渲染 |
| `web/src/components/McSeedPreview.tsx` | 页面：表单、地图、图层、历史 |
