# docs/screenshots —— README 用的界面截图

README 里的截图直接引用本目录（仓库内相对路径，由 GitHub 自己的 CDN 提供），
不再走任何图床——图床慢的时候整页都在等它，而仓库里的图跟着仓库走。

| 文件 | 拍的是什么 |
| --- | --- |
| `01-setup.webp` | 首启初始化（建管理员账号） |
| `02-main.webp` | 主界面 + 右下启动面板 |
| `03-instances.webp` | 实例列表页（左：dsh 实例 / 品牌实例两层） |
| `04-download.webp` | 下载页 |
| `05-settings.webp` | 设置页（通用） |
| `06-brands.webp` | 品牌实例层：品牌页签行 + 版本卡 + 实例卡（原地切换出来的那一层） |

## 规格与重新生成

- 视口 **1440×900**（`02-main` 原本是 1920×1080，已统一到 1440 宽）。
- 转成 **WebP，`-quality 82`，`-strip`**：六张合计约 **330 KB**（PNG 原图约 4 MB）。
  截图里全是 UI 文字，82 已经看不出差别；要更清晰就提到 88~90，代价是体积翻倍。
- 重新生成：

```bash
# 截图（面板跑起来、页面上有数据的状态），然后：
magick shot.png -strip -quality 82 docs/screenshots/03-instances.webp
```

- 2026-10-16 这一批是在**一份演示数据集**上拍的：9 个 dsh 实例（名字是中性的
  `web-agent` / `docs-bot` / `research` / …）+ 1 个 kimi + 1 个 zcode 实例，
  管理员账号为 `admin`，**没有真实账号/供应商/路径/口令**。

> 换图前务必确认页面上没有不该公开的东西（内网域名、口令、真实账号名、实例 URL 里的
> `?token=`）——这是截图最容易漏的一步。实例运行中时列表与浮层都会带上 token，
> 所以列表截图请让实例处于停止态。
